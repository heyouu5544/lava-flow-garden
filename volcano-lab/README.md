# Volcano Lab｜火山实验室

面向普通观众与学生的双参数火山实验。独立编写，使用原生 HTML、CSS、JavaScript 和 Canvas，无外部运行依赖。

## 运行

直接用现代浏览器打开 `index.html` 即可。也可以通过编辑器的 Live Server 打开。不需要安装依赖、构建、后端、API 或联网；页面中的科学资料链接仅供自愿阅读。

1. 调整岩浆黏度与气体含量（0–100 教学相对指数）。
2. 点击 **Trigger eruption**，观察约 7 秒的动画及四项结果和解释。
3. 动画结束后可以调整参数、再次喷发。旧结果会保留并标注原参数，直到下一次触发。
4. **Reset** 随时取消当前动画，将两个参数恢复为 40，清空结果及实验编号。

运行期间锁定滑块。触发按钮通过 `aria-disabled` 表示不可用，但保留键盘焦点与点击事件，以便再次尝试时给出提示；处理函数会阻止任何重复动画。支持键盘操作、文字结果、屏幕阅读器状态提示和系统“减少动态效果”设置（静态展示最终图像，实验仍约 7 秒完成）。

## 教学模型

所有输出均为 0–100 相对指数，不是物理测量。令 `v = 黏度 / 100`、`g = 气体 / 100`：

- 气体推动与滞留组合：`e = g × (0.3 + 0.7v)`。
- 喷发强度：`round(5 + 95e)`。
- 火山灰高度：`round(2 + 98e)`。
- 熔岩流动：`round(8 + 92(1-v)(0.65 + 0.35g))`。
- 危险范围：`round(max(流动 × 0.65, 强度 × 0.94))`。

公式与系数为本演示自行设计，未经真实火山数据校准。低黏度使熔岩更容易铺展；气体增加会增强活动，高黏度会放大富气体组合的爆发倾向。危险范围同时考虑熔岩与爆发，不暗示弱爆发就是安全。黏度高、气体少时，模型不会产生强爆发。0 表示本教学范围的低端，而不是物理上的绝对零气体或零黏度。

一般科学原理参考：[USGS：How do volcanoes erupt?](https://www.usgs.gov/faqs/how-do-volcanoes-erupt)、[NPS：Volcanic Eruptions](https://www.nps.gov/subjects/volcanoes/volcanic-eruptions.htm)。公式并非上述机构提供。真实火山还涉及温度、岩浆成分、供给速率、地形、风场等；动画非真实比例，范围线不是安全边界，也不能用于避险决策。模型未单独模拟火山碎屑流、泥石流或气体毒性。

## 开发检查

安装 Node.js 的开发环境可运行 `node --test tests/model.test.cjs`，不需要第三方依赖。浏览器人工检查：两组相反参数、运行中重复触发、运行中重置、结束后再次实验、窄屏布局和键盘操作。实际同学试用请按 `PROCESS.md` 记录，勿把开发检查当成用户测试。
