# VOLCANO LAB / 二维地质档案

已将现有火山实验室统一重绘为纸白、炭黑、岩石灰与深红的二维版画视觉。使用原生 HTML、CSS 和 Canvas，无外部运行依赖，可离线使用。

## 本地预览

在工作区根目录执行：

```powershell
node volcano-lab/serve.cjs
```

访问 http://127.0.0.1:4173/ 查看完整开场；http://127.0.0.1:4173/lab.html 直接进入实验台。也可直接打开 index.html / lab.html。端口仅监听本机。未提交、未推送 GitHub，未发布托管网站。

## 二维表现

山体线描、岩层、蚀刻与网点由代码绘制并缓存，不使用整张参考图。地形等高线留在淡灰背景，功能界面保持高对比。熔岩具有不规则边缘、延伸、分叉、移动纹理和深色冷却岩壳；高黏度低气体组合增加近口穹丘。灰云以不规则烟团、网点表现翻卷、膨胀与淡出。碎屑数量、飞散距离、脉冲节奏、放射线与短暂震动受气体和强度影响。

观察按钮以实底、双重边框和 ✓ 标记选中，默认/悬停/按下/禁用状态均有区别。窄屏改为先观察场景、再调整参数，触发时自动滚回场景。支持鼠标、触屏和键盘。

## 文件

- index.html / lab.html：同一套界面，入口分别为开场和实验。
- print.css：统一版画视觉、响应式、按钮与滑块状态。
- js/scene.js：二维绘制、三层视差、镜头、剖面与喷发。
- js/observer.js：观察目标说明和可访问场景文字。
- js/story.js：镜头巡游、五章介绍、跳过与原场景展开。
- js/app.js：参数、喷发生命周期、结果、Reset 与历史展示。
- js/model.js / js/history.js：后续版本教学模型与案例选择逻辑。
- serve.cjs：无依赖的本机静态预览服务器。
- screenshots/：本次本地浏览器实测截图。
- VERIFICATION.md：逐项验证结果。

原 styles.css、journey.css、js/webgl.js 与旧 preview.png 留作历史资料，当前入口不再加载它们，也不依赖 Three.js / WebGL。
