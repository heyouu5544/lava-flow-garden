# Volcano Lab｜火山实验室

面向普通观众和学生的火山教学实验：调节岩浆黏度与气体含量，触发喷发，比较熔岩、火山灰、强度和危险范围，再阅读解释与历史喷发类比。村庄仅呈现环境尺度，没有障碍、出口选择、保护村庄、倒计时或评分玩法。

## 运行

保留仓库目录结构，直接打开 `volcano-lab/index.html`，或直接打开 `volcano-lab/lab.html` 进入实验。使用原生 HTML、CSS、JavaScript 和仓库已有的 `../three.min.js`，没有构建步骤、后端或在线 API；没有新增下载的模型或贴图。

也可在 **lava-flow-garden 仓库根目录**启动静态服务器：

```sh
python -m http.server 8000
```

访问 `http://localhost:8000/volcano-lab/index.html`。请勿只复制子目录而遗漏父目录的 Three.js；库缺失时会降级为二维示意。历史资料链接需要联网，实验本身不需要。

## 操作与流程

- 开场标题 → 开始探索 → 全景、村庄、山体、火山口镜头 → 五段文字介绍 → 实验室。开场和讲解统一使用暖色三维场景；没有黑白手绘转场或录制旁白。“跳过介绍”可直接进入实验室。
- 两项滑块为 0–100 教学相对指数。四个预设便于比较平静溢流、熔岩喷泉、近口堆积和爆炸喷发。
- 点 **Trigger eruption** 立即开始约 8.5 秒动画，经历压力积累、释放和稳定。运行中按钮显示“喷发进行中”，实际禁用按钮、滑块与预设，防止叠加。
- 完成后展开解释与历史对照。调整参数不会改写上一组记录，需再次触发才能更新。Reset 随时中止实验，恢复 40/40、初始视角和界面。
- 拖动旋转、滚轮或双指缩放；视角按钮平滑移动到正面、侧面和俯视。部位按钮靠近目标并显示说明，再次点击可重新聚焦。键盘可通过 Tab、方向键和 Enter 操作控件。

## 模型与画面

地形采用细分网格、噪声位移、不对称山脊、侵蚀沟壑和分层颜色；火山口包含外缘、内壁、裂隙和内部熔岩光。石屋、院墙、道路、农田、水渠、塔楼、棕榈与岩石由代码生成，房屋和植物等使用 InstancedMesh。程序纹理、暖光、阴影、远山、渐变天空与距离雾提供空间层次。像素比上限 1.5，粒子数量固定。

熔岩使用沿地表采样的变宽带状网格，逐段延伸、分支并覆盖带裂隙的暗色冷却层；低黏度流得更快更远，高黏度主要形成短流和近口堆积。灰云使用透明粒子上升、扩张、卷动、漂移与淡出，配合喷出物、火花、扬尘、冲击波和有限镜头震动。声音是可选的浏览器合成提示音，不是真实喷发录音。

## 教学限制与资料

所有指数都不是实际黏度、气体百分比、距离、高度或 VEI；危险表现与范围不能用作预测或安全边界。真实喷发还受温度、成分、晶体、供给、地下水、地形与风向等影响。历史卡片只类比部分表现，不复现或预测真实事件；没有合适匹配时明确显示“没有足够相似的案例”。

案例链接见卡片，主要来源为 USGS，包括 [Maunaulu 1969–1974](https://www.usgs.gov/volcanoes/kilauea/science/1969-1974-maunaulu-eruption)、[圣海伦斯山 2004–2008](https://www.usgs.gov/volcanoes/mount-st.-helens/science/2004-2008-renewed-volcanic-activity) 和 [皮纳图博 1991](https://pubs.usgs.gov/fs/1997/fs113-97/)。本轮保留既有案例资料，没有新增未经核实的历史事件。

三维初始化失败时显示明确提示并降级；可通过 `lab.html?render=2d` 预览。实验逻辑和文字结果独立于三维渲染。减少动态效果偏好会跳过开场巡游。
