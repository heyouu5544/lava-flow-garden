# Volcano Lab 开发记录与用户测试

## 当前实现

采用统一暖色三维开场、知识讲解和实验场景，删除开场中的黑白、红色手绘档案转场。视觉方向是干燥火山地貌、石屋聚落、暖光、远山与电影式镜头；没有使用参考游戏的角色、Logo、建筑资源或现成场景。所有新增模型和纹理由代码生成，沿用仓库已有 Three.js。

地形细分与平滑法线、不对称山脊、侵蚀沟壑、火山口内壁、程序岩石纹理、建筑颜色差异、院墙道路、水渠农田和棕榈用于改善空间层次。熔岩改为变宽地表网格与裂隙冷却层；烟灰采用有限数量透明粒子，不再堆叠实体灰球。像素比限制 1.5，房屋、植被、岩石使用实例化。

这些仍是教学画面，不是地质数据重建或流体模拟。村庄用于尺度说明，未增加旧防灾游戏玩法。

## 2026-10-29 按钮修复与开发检查

按钮失效的直接原因：喷发处理访问了不存在的 results ID，真实点击时抛出空对象 dataset 错误。改为选择现有 .results 容器，并明确维护按钮 disabled、aria-disabled 和运行文字。另修复了渲染循环中未定义 result 的引用；纠正地表带状网格的三角形朝向，减少烟灰粒子过大的问题，并将熔岩移到正面易观察的坡面。移除会在天空产生矩形边缘的雾片，远山变形改为基于空间坐标，减少接缝。

## 同学用户测试：待完成

尚未邀请同学，不能把上述开发检查写成真实用户反馈。建议一次试用约 5–8 分钟，先不解释滑块：

1. 请同学进入开场，阅读或跳过介绍，找到实验操作。
2. 请其自行调出两种明显不同的喷发；每次先预测，再触发并描述所见。
3. 请其用自己的话解释黏度与气体怎样影响熔岩、灰柱和强度。
4. 询问困惑的标签、术语或位置；观察其是否误把历史类比当作复现或预测，是否误把范围当作安全界线。
5. 尝试 Reset 和再次实验，记录操作障碍，依据观察修改说明后再复测。
