# 美术与资料来源

## 本次原创素材

所有可见场景由 `js/scene.js` 的 Canvas 路径与代码绘制，界面由 `storybook.css` 绘制；没有下载或嵌入第三方插画、整张书页或外部字体。

- 背景：湖蓝天空、奶油太阳、淡紫远山、深蓝树林；背景、地形、前景独立缓存，镜头移动时具有不同视差。
- 火山：原创轮廓、八组不规则蓝紫与粉彩岩层、粗笔刷岩纹、石块、橙红火山口与明黄熔岩。
- 环境：原创树叶/枝干、紫色岩地、珊瑚橙屋顶、奶油墙面、蓝色水渠、粉紫农田和道路。
- 动态：分层奶油/灰蓝/淡紫云团、熔岩流动笔触、喷泉弧线、碎屑、气泡与烟柱。参数控制流动速度/长度/厚度、穹丘生长、喷射和烟柱形态。
- 质感：确定性伪随机颗粒、颜色覆盖、粗糙路径轮廓、干笔刷痕；Canvas 颗粒在场景中缓存，CSS 的内嵌 SVG 噪声为全界面提供轻纸张质感。
- 字体：系统 `Impact` / `Arial Black` 标题及 Segoe UI / Microsoft YaHei 正文。倾斜标题、错位描边、纸纹叠加与不规则圆角构成手绘字面与组件。

用户上传的前两张火山绘本和第三张对话框仅作为色彩、笔触与结构参考。未使用其书名、作者文字、插画成品或截图作为页面素材；构图和内容均独立制作。
